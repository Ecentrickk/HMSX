🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Node.js not found" error
SOLUTION:
  1. Install Node.js from https://nodejs.org (version 18+)
  2. Restart the computer
  3. Try again: .\start-h1ms.bat

PROBLEM: "Cannot connect to MongoDB"
SOLUTION:
  1. Verify MongoDB is running/accessible
  2. Check connection string is correct
  3. Test connection manually if possible
  4. Contact MongoDB support if server issues

PROBLEM: "Port 3000 already in use"
SOLUTION:
  1. Stop H1MS (Ctrl+C)
  2. Edit: .env file
  3. Find: PORT=3000
  4. Change: PORT=3001
  5. Save and restart: .\start-h1ms.bat
  6. Access: http://localhost:3001

PROBLEM: "Cannot access http://localhost:3000"
SOLUTION:
  1. Verify H1MS is running (check command window)
  2. Try: http://127.0.0.1:3000
  3. Check Windows Firewall (may need to allow port 3000)
  4. Try different browser

PROBLEM: "Forgot administrator password"
SOLUTION:
  1. Create new admin account:
  2. Stop H1MS (Ctrl+C)
  3. Run: node tools\create-admin.mjs
  4. Follow prompts to create new admin
  5. Restart H1MS
